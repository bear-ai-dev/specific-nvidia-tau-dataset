# Telecom data-support policy

Resolve one customer using the mobile number, full name, and date of birth before disclosing line, device, usage, or billing details. Keep the resolved line and billing cycle consistent throughout the call.

Compare carrier-recorded usage with the customer's device-side app evidence before attributing a cause. Do not characterize unexpected usage as hacking without evidence. State the measured usage, remaining high-speed allowance, billing-cycle reset, and any current overage accurately.

Phone settings, app permissions, Data Saver, and speed tests are customer-side actions. Guide the customer and rely on their spoken confirmation; do not represent those actions as agent backend function calls.

Explain that already-consumed data cannot be restored. Before adding paid data, state the amount, price, billing timing, and resulting allowance, then obtain explicit authorization. The add-on mutation must return the charged price and updated high-speed balance.

Do not guarantee a particular throttled or test speed. If unexplained idle usage continues after the settings cleanup, escalate for further account or security investigation.
